# Deployment-Pipeline-Frontend

This is the React.js (Vite) frontend for the Deployment Pipeline Platform.  
It provides an intuitive user interface to manage project creation, deployment, and access control.

---

## Project Overview

The frontend acts as the visual control layer of the platform, communicating with backend APIs to:
- Create and manage projects
- Trigger deployment processes
- Manage user roles and permissions

## Tech Stack

- React.js (Vite)
- JavaScript
- Axios for API requests

- TailwindCSS / CSS Modules for styling 
- Jest for unit testing
